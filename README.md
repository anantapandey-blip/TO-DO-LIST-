 TO-DO-LIST-
This is a Python To-Do App created using basic Object-Oriented Programming (OOP) concepts.
 

 About the Project

The project creates different task lists containing:

* Personal tasks
* Professional tasks

The tasks are stored using a Python class and displayed using a class method.

## Concepts Used

* Python
* Classes and Objects
* `__init__()` constructor
* Instance attributes
* Methods

###  Purpose

This project was created to practice and strengthen my understanding of **Python OOP concepts**.

This is yet another practice project as part of my Python learning journey.
